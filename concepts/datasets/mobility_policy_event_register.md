# Mobility policy event register

## Summary

A reusable event file of travel bans, visa restrictions, Brexit-like exits, and funding-access changes can support studies of mobility shocks and scientific capacity.

## Canonical Form

- Unit of analysis: policy event affecting scientific mobility.
- Typical representation: event-date table with affected origins, destinations, mechanisms, and expected exposure.
- Dataset target: structured policy-shock registry for mobility and collaboration studies.
- Empirical signature: mobility or collaboration outcomes can be aligned to plausibly exogenous policy timing.

## Uses in Science of Science

- Provides input data for [mobility policy shock evaluation](../validations/mobility_policy_shock_evaluation.md).
- Useful for comparing isolationist, visa, funding-access, and cross-border program shocks.
- Connects policy events to [central-country mobility displacement](../mechanisms/central_country_mobility_displacement.md).

## Operationalization

- Code event date, announcement date, implementation date, affected origins/destinations, policy mechanism, funding eligibility, and expected route exposure.
- Link events to author-affiliation histories, applications, visas, collaborations, and publications.
- Version the registry because policies are revised and contested over time.

## Evidence and Validations

- Verified full-text evidence from Sugimoto et al. (2017) discusses US travel bans, UK withdrawal from the European Union, visa-renewal restrictions, and European project barriers as mobility-relevant events.
- The article motivates but does not itself build a reusable event registry.

## Caveats

- Policy timing can be anticipated, phased, litigated, or unevenly enforced.
- Exposure coding should distinguish formal restrictions from perceived climate and funding uncertainty.

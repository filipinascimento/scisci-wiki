# Mosaic-interface portfolio value

## Summary

Diverse portfolios can create value at interfaces among options, where combinations, translations, and mosaics generate outcomes unavailable to isolated trajectories.

## Canonical Form

- Unit of analysis: portfolio option, interface, combination, interdisciplinary relation, or emergent outcome.
- Typical representation: interface-value model of interactions among heterogeneous options.
- Mechanism, measurement, or validation target: synergistic value from diversity beyond independent option performance.
- Empirical signature: portfolio value exceeds the sum of isolated option values when interfaces enable recombination or mutual learning.

- Connects diversity value mechanism to [portfolio interaction diversity value](../methods/portfolio_interaction_diversity_value.md) and [science technology diversity governance](science_technology_diversity_governance.md).

## Operationalization

- Identify interfaces where fields, methods, or technologies interact.
- Measure outcomes from combinations as distinct from isolated option performance.
- Use network or portfolio models that allow interaction terms rather than additive-only diversity effects.

## Evidence and Validations

- Verified full-text evidence from Stirling (2007) treats diversity as more than category count and situates it in systems of science, technology, and society.
- The framework supports interaction value among heterogeneous options in research portfolios.

## Caveats

- Interface value is difficult to attribute and may be delayed.
- Some interfaces create coordination costs or conflict rather than synergy.

# Search path link count

## Summary

Search path link count is a traversal measure that counts how often each directed citation edge appears across all search paths from a chosen origin.

## Canonical Form

- Unit of analysis: directed citation edge, source node, search path, or bounded citation network.
- Typical representation: edge-weighted citation network where each edge receives an SPLC traversal count.
- Mechanism or measurement target: link importance as repeated use across possible routes through a literature.
- Empirical signature: edges on the main developmental route carry high traversal counts because many source-to-downstream paths pass through them.

## Uses in Science of Science

- Operationalizes the edge-weighting step inside [main path analysis](../methods/main_path_analysis.md).
- Converts [citation networks](../representations/citation_networks.md) into path-weighted backbones rather than node-centric citation-count rankings.
- Provides a simpler traversal-count alternative to [search path node pair count](search_path_node_pair_count.md) and [node pair projection count](node_pair_projection_count.md).

## Operationalization

- Prepare a directed acyclic citation network and select an origin node or source set.
- Generate all possible search paths through the network from the origin.
- Count the number of generated search paths that traverse each directed edge.
- Use the resulting SPLC edge weights for main-path extraction, edge ranking, or comparison with other traversal-count measures.

## Evidence and Validations

- Verified full-text evidence from Hummon and Doreian (1989) defines search path link count as counting the number of times a link is traversed by all possible search paths generated by exhaustive search.
- In their DNA network, the SPLC method identifies link 27-32 as having the maximum traversal count, and the high-count links align with the Watson-Crick and Ochoa portion of the historical sequence.
- The paper shows that SPLC can define the same main path as the other traversal-count variants in the DNA case.

## Caveats

- SPLC depends on the selected origin and on whether all plausible source nodes are considered.
- Edges near the origin or terminal nodes may be treated differently than in node-pair-weighted variants.
- Exhaustive search can be expensive in large DAGs unless implemented with dynamic programming or pruning.

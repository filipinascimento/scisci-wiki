# Source-repository provider coupling disclosure

## Summary

Records when the same provider ecosystem supplies the citation source and hosts the released metric artifact.

## Canonical Form

- Unit of analysis: data source, repository, provider, and metric release.
- Typical representation: provider-role manifest for source, hosting, update control, correction route, and access terms.
- Validation target: provenance and governance transparency for released bibliometric resources.
- Empirical signature: one commercial or institutional ecosystem controls several stages of the metric supply chain.

## Uses in Science of Science

- Extends [bibliometric data access modes](../methods/bibliometric_data_access_modes.md) with a governance disclosure.
- Useful for source-derived metric tables released through provider-owned repositories.
- Connects Scopus-based indicators to [commercial metric provider accountability](commercial_metric_provider_accountability.md).

## Operationalization

- Add a provider-role manifest for source database, repository, author affiliation, update control, access route, and correction pathway.
- State which pieces are open, proprietary, reproducible, or provider-mediated.
- Track whether corrections require provider action or independent recomputation.

## Evidence and Validations

- Verified full-text evidence from Ioannidis et al. (2019) identifies Elsevier as operating Scopus, the data source, and Mendeley Data, the repository for the released artifact.
- The dual role motivates explicit provider-coupling disclosure.

## Caveats

- Provider coupling does not invalidate a resource; it marks provenance and governance to audit.
- Independent mirrors may still depend on proprietary source data.

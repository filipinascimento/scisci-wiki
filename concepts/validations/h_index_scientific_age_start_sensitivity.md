# h-index scientific-age start sensitivity

## Summary

h-index scientific-age start sensitivity audits whether first publication is an appropriate starting point for seniority-adjusted h-index comparisons.

## Canonical Form

- Unit of analysis: author, first publication year, scientific age, h-index, or m-quotient.
- Typical validation: compare alternative career-start definitions before dividing h by career length.
- Validation target: denominator validity for age-adjusted author metrics.
- Empirical signature: m-quotient values can change when scientific age is measured from a different start date.

## Uses in Science of Science

- Bounds interpretation of [m-quotient](../measures/m_quotient.md).
- Adds career-timing caution to [h-index](../measures/h_index.md).
- Connects to [career-spanning citation-source coverage](../methods/career_spanning_citation_source_coverage.md).
- Supports responsible use of author metrics in evaluation.

## Operationalization

- Record first publication year and alternative career-start markers.
- Compute scientific age under each definition.
- Compare h divided by each age denominator.
- Report when early publications, career gaps, or delayed database coverage affect the result.

## Evidence and Validations

- Verified full-text evidence from Hirsch (2005) defines scientific age using years since first publication when discussing the m-quotient.
- The paper also notes practical issues in obtaining and interpreting publication histories.
- This motivates auditing whether the first publication date is a valid denominator for the assessment context.

## Caveats

- First publication can predate independent research activity.
- Database coverage may miss early papers.
- Career breaks and field changes can make chronological scientific age misleading.

# Multidisciplinary journal exception set

## Summary

Multiple journal assignments should be preserved only for broad journals whose citation behavior remains multidisciplinary after audit.

## Canonical Form

- Unit of analysis: multidisciplinary journal, assignment exception, citation profile, self-citation, relative importance profile, or subdiscipline label.
- Typical representation: audited exception list for journals retained as multi-assigned sources.
- Mechanism, measurement, or validation target: validation of broad-journal handling in journal-level maps.
- Empirical signature: a small set of broad journals remains multiply assigned after citation-flow and self-citation audits.

## Uses in Science of Science

- Refines science-map validation by linking it to [multipoint journal fractional assignment](../methods/multipoint_journal_fractional_assignment.md) and [disciplinary independence](../measures/disciplinary_independence.md).
- Useful as a reusable check when [science map accuracy validation](science_map_accuracy_validation.md) is used in science-of-science inference.
- Creates cross-links to [journal impact factor](../measures/journal_impact_factor.md) so the motif is not interpreted in isolation.

## Operationalization

- Audit high-breadth journals using absolute and normalized citations and references.
- Remove journal self-citations before evaluating broadness.
- Retain multiple assignments only when no defensible single category emerges.

## Evidence and Validations

- Verified full-text evidence from Borner et al. (2012) reports manual examination of 40 previously multipoint journals and retention of exceptions including Science, Nature, Lancet, BMJ, and JAMA.
- The exception set documents where the one-journal-one-field simplification should not be applied.

## Caveats

- Exception membership is historically contingent and threshold-sensitive.
- Broad journals can change scope over time and should be reaudited in map updates.

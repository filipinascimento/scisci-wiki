# Science-map common reference system

## Summary

A science-map common reference system treats a global map of science as shared coordinates for locating data, documents, expertise, results, and discoveries across disciplinary boundaries.

## Canonical Form

- Unit of analysis: paper, journal, discipline, expertise profile, dataset, document, result, or discovery claim.
- Typical representation: map coordinate, region identifier, overlay layer, lookup table, or shared science-location index.
- Representation target: provide common spatial context for heterogeneous scholarly objects.
- Empirical signature: different data streams can be placed on the same base map and navigated using common locations.

## Uses in Science of Science

- Generalizes [science maps](science_maps.md) from static visualizations into indexing infrastructure.
- Connects [science map overlays](science_map_overlays.md) and [science-location lookup tables](../methods/science_location_lookup_tables.md).
- Uses the [science-map source-title spine](../datasets/science_map_source_title_spine.md) as one possible base-map reference layer.
- Supports search, expertise discovery, communication, and portfolio comparison across fragmented literatures.

## Operationalization

- Build or select a stable base map with documented units, coordinates, and versioning.
- Assign incoming scholarly objects to map locations through journals, citations, text, concepts, or learned embeddings.
- Preserve uncertainty, multi-location assignments, and source provenance.
- Expose the map as a lookup table or service so multiple applications can share the same coordinate system.
- Record when map updates require coordinate migration or backward-compatible crosswalks.

## Evidence and Validations

- Verified full-text evidence from Boyack, Klavans, and Borner (2005) argues that global science maps could help researchers and practitioners search across scientific boundaries and counteract fragmentation.
- The paper explicitly analogizes science maps to earth or astronomical coordinates: a shared reference system for indexing and retrieving data, documents, and expertise.
- This reference-system view connects map construction to discovery announcement, result communication, and database search quality rather than only to visual layout.

## Caveats

- A single reference map may privilege dominant fields and source databases.
- Coordinate stability can conflict with updating the map as science changes.
- Some objects need multiplex or probabilistic locations rather than one coordinate.

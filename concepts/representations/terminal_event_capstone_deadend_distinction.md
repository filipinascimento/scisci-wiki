# Terminal-event capstone/dead-end distinction

## Summary

Terminal-event capstone/dead-end distinction represents terminal nodes in a citation-history network as either productive capstones for future research or dead ends that do not feed the focal developmental stream.

## Canonical Form

- Unit of analysis: terminal citation-network node, milestone event, generation cluster, observation window, or field-history endpoint.
- Typical representation: terminal-node labels separating capstones, dead ends, and unresolved endpoints.
- Representation target: avoid treating every terminal event in a bounded historical network as substantively equivalent.
- Empirical signature: some terminal events close off unextended lines, while others represent recent capstones on which later work can build.

## Uses in Science of Science

- Refines [regular equivalence intellectual generations](../methods/regular_equivalence_intellectual_generations.md) by splitting terminal-generation nodes.
- Provides a path-history caveat for [main path analysis](../methods/main_path_analysis.md) and [research fronts](../mechanisms/research_fronts.md).
- Helps distinguish real intellectual dead ends from right-censoring at the end of the observation window.
- Gives historians and bibliometricians a label set for interpreting terminal nodes after path or equivalence analysis.

## Operationalization

- Identify terminal nodes in a directed citation or cited-by dependency graph.
- Inspect whether each terminal event is old enough to have received downstream citations or whether it sits at the observation-window boundary.
- Label endpoints as dead ends, capstones, or unresolved based on subsequent uptake, historical reading, and relation to later fields.
- Compare labels with generation clusters and main-path membership.
- Preserve labels as interpretive annotations rather than treating them as automatic graph properties.

## Evidence and Validations

- Verified full-text evidence from Hummon and Doreian (1989) uses regular-equivalence clustering to identify terminal events in the DNA citation network.
- The authors state that some terminal events appear to be dead ends, while other terminal events are capstones on which future research can be built.
- Their distinction shows why terminal position alone is insufficient for interpreting historical significance.

## Caveats

- Recent terminal nodes may only be censored rather than dead ends.
- Dead-end labels can change when the corpus, citation window, or later knowledge domain is expanded.
- Capstone status requires historical interpretation and should not be inferred solely from zero outgoing links in a bounded graph.

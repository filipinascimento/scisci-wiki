# Diversity-component map grammar

## Summary

Diversity-component map grammar is the representation in which science-map overlays encode interdisciplinarity components visually: variety as number of nodes, balance as node sizes, and disparity as distance among nodes.

## Canonical Form

- Unit of analysis: field-year overlay, subject category, cited-reference profile, diversity component, or science map.
- Typical representation: overlay nodes and distances used as a visual grammar for variety, balance, and disparity.
- Representation target: make numerical interdisciplinarity components interpretable on a science map.
- Empirical signature: more nodes, more even node sizes, and larger map spread indicate different dimensions of diversity.

## Uses in Science of Science

- Refines [science map overlays](science_map_overlays.md).
- Adds a visual layer to [field-year cited SC overlay](field_year_cited_sc_overlay.md).
- Connects to [interdisciplinarity dimensions](../measures/interdisciplinarity_dimensions.md).
- Helps readers see why a single diversity score can hide component differences.

## Operationalization

- Build a base map of subject categories or fields.
- Overlay a field-year reference profile on the base map.
- Interpret node count as variety, node-area distribution as balance, and between-node distance as disparity.
- Pair the visual interpretation with numeric diversity measures.

## Evidence and Validations

- Verified full-text evidence from Porter and Rafols (2009) maps cited subject categories to visualize interdisciplinarity.
- The paper explicitly relates map spread and subject-category distribution to diversity components.
- This creates a map grammar for interpreting changes in knowledge integration over time.

## Caveats

- Map distance depends on the similarity matrix and projection choices.
- Node-size visual salience can exaggerate or hide balance.
- Visual grammar supports interpretation but does not replace numeric validation.

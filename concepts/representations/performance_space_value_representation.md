# Performance-space value representation

## Summary

Performance-space value representation models portfolio elements as points or scores across weighted performance criteria so diversity can be articulated with non-diversity values.

## Canonical Form

- Unit of analysis: research option, technology, field, institution, habitat, portfolio element, performance criterion, or stakeholder perspective.
- Typical representation: weighted performance matrix, m-dimensional performance space, value-score table, or option-criteria map.
- Representation target: make individual option performance explicit before combining it with diversity and portfolio interaction value.
- Empirical signature: the same portfolio elements receive different value scores under different criteria weights or stakeholder perspectives.

## Uses in Science of Science

- Supplies the non-diversity value layer for [diversity-performance trade-off frontier](../methods/diversity_performance_tradeoff_frontier.md).
- Complements [perspective-dependent disparity space](perspective_dependent_disparity_space.md): disparity space models differences among options, while performance space models option value.
- Links diversity metrics to [funding-allocation design alternatives](../methods/funding_allocation_design_alternatives.md), responsible portfolio assessment, and research governance.
- Makes value assumptions visible when comparing field portfolios, funding programs, research strategies, or infrastructure investments.

## Operationalization

- Define a set of performance criteria such as expected impact, equity, cost, resilience, security, environmental effect, feasibility, or societal value.
- Score each option on each criterion using data, expert elicitation, or transparent qualitative coding.
- Assign criterion weights for each analytic or stakeholder perspective.
- Combine scores and portfolio shares to estimate aggregate option-performance value.
- Report sensitivity to criterion inclusion, scaling, and weights before adding diversity or interaction terms.

## Evidence and Validations

- Verified full-text evidence from Stirling (2007) represents divergent valuations of individual system elements as coordinates in an m-dimensional Euclidean performance space.
- The paper states that dimensions of this space represent performance criteria, each weighted to reflect their importance for a given perspective and context.
- Stirling uses this representation to articulate individual option performance with diversity and portfolio-level properties in a system-value heuristic.
- The full text illustrates the idea with habitat and energy portfolios, where criteria can include ecological, economic, socio-cultural, environmental, security, and operational concerns.

## Caveats

- Performance-space scores can appear precise even when they are based on contested values or uncertain forecasts.
- Criterion weights should be reported separately for each perspective instead of hidden in a single aggregate score.
- Option performance may change with scale, time, learning, or interactions with other portfolio elements.
- Performance-space modeling does not remove the need for qualitative deliberation over which criteria matter.

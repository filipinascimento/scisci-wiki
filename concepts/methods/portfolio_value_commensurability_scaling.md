# Portfolio-value commensurability scaling

## Summary

Comparing diverse portfolios requires making value dimensions commensurable or explicitly preserving noncommensurable dimensions before aggregation.

## Canonical Form

- Unit of analysis: portfolio option, value dimension, performance measure, scaling rule, or aggregation weight.
- Typical representation: value-scaling protocol for aggregating or comparing heterogeneous portfolio performance dimensions.
- Mechanism, measurement, or validation target: how diversity and performance are compared across heterogeneous values.
- Empirical signature: portfolio rankings change when value dimensions are rescaled, weighted, or kept separate.

## Operationalization

- Identify performance and value dimensions before computing portfolio scores.
- Choose scaling and aggregation rules, or keep dimensions separate when commensurability is not defensible.
- Run sensitivity analyses over scaling and weighting choices.

## Evidence and Validations

- Verified full-text evidence from Stirling (2007) connects diversity appraisal to plurality of perspectives and values.
- The paper's attention to aggregation, accommodation, and articulation motivates explicit scaling of value dimensions.

## Caveats

- Scaling can make unlike values appear comparable when stakeholders reject that assumption.
- Commensurability choices can dominate diversity-performance conclusions.

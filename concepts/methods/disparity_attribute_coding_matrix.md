# Disparity attribute-coding matrix

## Summary

Category disparity can be derived from a matrix of attributes that define how options differ, rather than assumed from category labels alone.

## Canonical Form

- Unit of analysis: category, option, attribute, attribute weight, distance, or disparity matrix.
- Typical representation: category-by-attribute coding table transformed into pairwise disparity values.
- Mechanism, measurement, or validation target: constructing disparity spaces for diversity analysis.
- Empirical signature: diversity scores change when category differences are coded through different attribute sets or weights.

## Uses in Science of Science

- Connects diversity disparity construction to [perspective dependent disparity space](../representations/perspective_dependent_disparity_space.md) and [category disparity](../measures/category_disparity.md).
- Provides a reusable motif for comparing [average subject category dissimilarity](../measures/average_subject_category_dissimilarity.md) with adjacent science-of-science constructs.
- Should be cross-referenced when interpreting [disparity geometry assumption](../validations/disparity_geometry_assumption.md) in linked scholarly data.

## Operationalization

- Define the attributes that matter for the appraisal context.
- Code categories or options by those attributes and compute pairwise disparity.
- Sensitivity-test attribute inclusion, weighting, scaling, and distance functions.

## Evidence and Validations

- Verified full-text evidence from Stirling (2007) treats disparity as a distinct property and emphasizes dependence on perspective and category definitions.
- Attribute coding provides a concrete method for making those perspective-dependent distances explicit.

## Caveats

- Attribute selection is value-laden and should be documented.
- Distance matrices derived from attributes can appear objective while embedding subjective weights.

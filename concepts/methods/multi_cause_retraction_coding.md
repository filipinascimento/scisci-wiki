# Multi-cause retraction coding

## Summary

Multi-cause retraction coding allows a retracted article to carry more than one cause label when misconduct, error, duplication, plagiarism, or other problems overlap.

## Canonical Form

- Unit of analysis: retracted article, retraction notice, external investigation report, cause label, or coding decision.
- Typical representation: multi-label cause matrix rather than a mutually exclusive cause column.
- Method target: preserve complex correction evidence without forcing one dominant cause.
- Empirical signature: cause-category totals can exceed the number of retracted articles because some cases have multiple labels.

## Uses in Science of Science

- Refines [retraction cause taxonomies](retraction_cause_taxonomies.md) for ambiguous or compound cases.
- Supports [retraction source reconciliation](retraction_source_reconciliation.md) when notices and secondary sources imply different causes.
- Makes [misconduct retraction share](../measures/misconduct_retraction_share.md) more transparent by exposing overlap among fraud, plagiarism, duplication, and error.
- Adds coding detail to [retractions and scientific self-correction](../validations/retractions_self_correction.md).

## Operationalization

- Define a controlled vocabulary of cause categories.
- Allow each retracted article to receive zero, one, or multiple cause labels.
- Record the evidence source for each label, such as notice text, ORI report, journal statement, or public investigation.
- Report both article counts and cause-label counts.
- State how unknown and other categories interact with specific labels.

## Evidence and Validations

- Verified full-text evidence from Fang, Steen, and Casadevall (2012) classifies retractions by fraud, suspected fraud, plagiarism, duplicate publication, error, unknown, and other causes.
- Their table notes that some articles fall into more than one category.
- Treating cause coding as multi-label prevents overlap from being hidden inside a single residual category.

## Caveats

- Multi-label coding can make shares harder to compare unless denominators are explicit.
- Labels depend on notice quality and external investigation access.
- Coders need consistent rules for when suspected and documented causes coexist.

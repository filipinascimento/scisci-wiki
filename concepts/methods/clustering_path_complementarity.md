# Clustering path complementarity

## Summary

Clustering path complementarity is the methodological principle that citation-network clustering and path-based connectivity answer different questions and should be treated as complementary views of field structure.

## Canonical Form

- Unit of analysis: citation network, cluster, path, research specialty, intellectual generation, or field-history map.
- Typical representation: side-by-side cluster partitions and main paths, or a path backbone overlaid on clustered regions.
- Mechanism or measurement target: topical grouping versus developmental linkage.
- Empirical signature: clusters summarize coherent areas or generations, while paths trace strands that connect productions through time.

## Uses in Science of Science

- Helps decide when to use [co-citation](../representations/co_citation.md), [bibliographic coupling](../representations/bibliographic_coupling.md), regular equivalence, or [main path analysis](main_path_analysis.md).
- Prevents overinterpreting a cluster as a chronological development path or a path as a complete field partition.
- Supports richer [science maps](../representations/science_maps.md) that show both area structure and developmental backbones.
- Links structural-equivalence and regular-equivalence approaches to citation-path analysis.

## Operationalization

- Build a citation network for the same bounded corpus.
- Generate cluster or equivalence partitions using co-citation, bibliographic coupling, structural equivalence, regular equivalence, or related methods.
- Extract one or more main paths or high-traversal link backbones.
- Compare what clusters and paths explain: topical areas, generations, dead ends, capstones, and connective strands.
- Use disagreement between the views as a prompt for full-text or historical reading.
- Use [regular equivalence intellectual generations](regular_equivalence_intellectual_generations.md) when the aim is to compare path strands with dependency-position clusters.

## Evidence and Validations

- Verified full-text evidence from Hummon and Doreian (1989) states that clustering citation networks has objectives different from connectivity analysis and can be seen as complementary.
- Their discussion contrasts co-citation clusters, bibliographic coupling, structural equivalence, regular equivalence, and path-based connectivity.
- In the DNA case, regular equivalence identifies intellectual generations, while main-path analysis preserves the developmental strands from initial work to terminal events.
- The same comparison motivates separate labels for terminal capstones versus dead ends and for breakthroughs that sit just off the main path.

## Caveats

- Complementary views can disagree because they emphasize different mechanisms, not necessarily because one is wrong.
- Cluster algorithms and path algorithms each have their own sensitivity to corpus boundaries and parameter choices.
- Integrated maps should avoid visual designs that imply unsupported causality between clusters.

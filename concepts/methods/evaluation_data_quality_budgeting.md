# Evaluation data-quality budgeting

## Summary

Consequential metric evaluations should budget explicit time, staff, and money for data collation, correction, and verification.

## Canonical Form

- Unit of analysis: evaluation project, data budget, curator, correction window, author match, or output record.
- Typical representation: data-quality work package attached to evaluation design.
- Mechanism, measurement, or validation target: resourcing needed for reliable evaluation data.
- Empirical signature: evaluation plans include dedicated resources for metadata correction and verification before decisions are made..

## Uses in Science of Science

- Adds resourcing to [evaluated-party data verification](../validations/evaluated_party_data_verification.md).
- Connects [research-ready table curation](research_ready_table_curation.md) to assessment governance.
- Useful for institutions procuring data and dashboards.

## Operationalization

- Create a data-quality budget line.
- Schedule pre-decision correction windows.
- Track staff time for author matching, affiliation repair, and output verification.

## Evidence and Validations

- Verified full-text evidence from Hicks et al. (2015) says accurate, high-quality evaluation data take time and money to collate and process and explicitly calls for budgeting this work.

## Caveats

- Better data quality cannot rescue an invalid evaluation construct.
- Data-quality budgets can bias toward well-resourced institutions unless shared infrastructure exists.
